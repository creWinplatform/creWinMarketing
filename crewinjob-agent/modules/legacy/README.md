# legacy/

Bu klasör, henüz web arayüzüne bağlanmamış agent modüllerini içerir.
Silinmediler — ilerleyen sprint'lerde UI'a eklenebilirler.

| Dosya | Açıklama | Neden beklemede? |
|-------|----------|-----------------|
| `scheduler.js` | Otomatik içerik zamanlama | Cron/queue altyapısı kurulmadı |
| `seo-technical.js` | Teknik SEO denetim aracı | SEO sekmesi geliştirilecek |
| `seo-keywords.js` | Anahtar kelime araştırma motor | SeoTab'a eklenecek |
| `performance.js` | Kampanya performans analitiği | Analytics entegrasyonu bekliyor |
| `seafarer-kpi.js` | Gemi adamı bazlı KPI hesaplamaları | KPI sekmesi genişletilecek |
